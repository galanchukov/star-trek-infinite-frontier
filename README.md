# STAR TREK: INFINITE FRONTIER

Фанатский мобильный idle/clicker-проект во вселенной телесериалов Star Trek.

## Текущий статус

`index.html` — исходный прототип из Gemini Canvas, сохранённый как baseline для дальнейшей разработки.

## Запуск

Откройте `index.html` через локальный статический сервер. Проект использует Tailwind CDN и Google Fonts.

## План структуры

- `css/` — стили и адаптивная раскладка
- `js/` — игровые системы и состояние
- `data/` — данные персонажей, кораблей и цивилизаций
- `assets/` — оригинальные изображения и игровые ресурсы

Изменения вносить поэтапно, сохраняя рабочую версию игры.

## Канон

Использовать события, персонажей, звания и визуальные особенности телесериалов Star Trek. Фильмы не включать в источники игрового канона.


## Модульная структура

Первый этап миграции вынесен в отдельные файлы без изменения игровой логики:

- `index.gemini-baseline.html` — неизменённая резервная копия исходника Gemini Canvas.
- `index.html` — точка входа приложения.
- `css/styles.css` — исходные стили.
- `data/game-data.js` — экономика, редкости, персонажи TOS, цивилизации, корабли, сектора, модули и исследования.
- `js/app.js` — игровой runtime, интерфейс, бой, сохранения и визуальные эффекты.

Скрипты подключаются как обычные классические скрипты в порядке: сначала данные, затем runtime. Это сохраняет доступность глобальных справочников без переписывания всей логики на ES-модули.

Графические листы пока не подключены. Их оригинальные файлы будут добавлены отдельно в `assets/`.
